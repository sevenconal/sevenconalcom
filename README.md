# Sevenç Önal — Kişisel Marka & Portfolyo Platformu

Bilgisayar Mühendisliği Öğrencisi & Yazılım Geliştirici **Sevenç Önal**'ın kişisel markası, teknik vizyonu, yetkinlikleri ve hizmetlerini sunan modern web platformu.

---

## 🚀 Teknolojik Mimarisi

- **Frontend Framework**: React 18 + TypeScript
- **Derleyici & Build Tool**: Vite
- **Stil & Tasarım**: Tailwind CSS + Custom Dark Theme (Glassmorphism & Radial Tech Grids)
- **İkonlar**: Lucide React Icons
- **Tipografi**: Google Fonts (`Inter` & `JetBrains Mono`)
- **SEO & Metada**: Open Graph, JSON-LD Schema.org Structured Data, `robots.txt`, `sitemap.xml`

---

## ⚡ Özellikler

1. **Hero & İnteraktif Geliştirici Terminali**:
   - Özelleştirilmiş geliştirici vizyonu ve durum rozeti
   - Sekmeli CLI simülatörü (`bio.sh`, `stack.json`, `interactive.cli`)
2. **Mühendislik Vizyonu (Hakkımda)**:
   - Teorik mühendislik temeli ile pratik üretim arasındaki yaklaşım
   - 4 Temel Sütun: Kullanıcı İhtiyacı, Veri & Veritabanı, Yazılım Mimarisi, Çalışan Ürün
3. **Kompakt Teknoloji Yığını**:
   - 5 grupta toplanmış (Programlama, Web, Mobil, Veritabanı, Araçlar) minimalist yetkinlik rozetleri
4. **Hizmetler & 6-Adım Çalışma Süreci**:
   - Kişisel & İşletme Web Siteleri, QR Menü Çözümleri, Otomasyonlar ve UX/Teknik İnceleme
   - `01 İhtiyacı Anlama` → `06 Teslim` şeffaf süreç akışı
5. **İletişim & Güvenlik**:
   - Client-side validation, anti-spam bot trap mekanizması ve panoya e-posta kopyalama desteği
6. **Command Palette (`Ctrl+K`)**:
   - Tüm site içinde klavye kısayolu ile anlık arama ve navigasyon

---

## 🛠️ Yerel Kurulum & Geliştirme

```bash
# Projeyi klonlayın
git clone https://github.com/sevenconal/sevenconalcom.git

# Proje dizinine gidin
cd sevenconalcom

# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Production build alın
npm run build
```
